# AI Powered Trip Planner ✈️

An AI-based travel planning web application that generates personalized travel itineraries using LLMs and smart recommendation logic.

---

# Features 🚀

- Personalized AI travel itinerary generation
- Vibe-based trip planning
  - Adventure
  - Religious
  - Leisure
- Smart budget allocation
- Season-aware recommendations
- Festival-aware travel suggestions
- Lightweight RAG integration
- Flask backend + HTML frontend
- Groq LLM integration
- AI-generated travel recommendations

---

# Tech Stack 🛠️

- Python
- Flask
- HTML
- CSS
- JavaScript
- Groq API
- LLM (Llama 3.3 70B)
- RAG (Retrieval-Augmented Generation)
